# Онлайн челленджи

Android-приложение и публичный сайт для челленджей по активности: шаги, пробежки,
сон, отжимания, приседания, планка и пресс. Участники ставят измеримые цели,
каждый день вносят результат и получают баллы: фото/видео или галочка другого
участника подтверждает выполнение. Итоги и медали публикуются на GitHub Pages.

- Сайт: <https://romanlyavin.github.io/online-challenges/>
- APK: [OnlineChallenges-1.0.2.apk](OnlineChallenges-1.0.2.apk) · [последний релиз](https://github.com/RomanLyavin/online-challenges/releases/latest)
- Пакет: `com.onlinechallenges.app`
- Минимальная версия Android: 8.0 (API 26), целевая — API 35

## Как начисляются баллы

Один балл даётся за каждую **полностью выполненную цель**, к которой приложено
подходящее подтверждение: фото/видео или галочка другого участника. Частичный
результат баллов не даёт, превышение цели ничего не добавляет.

| Режим | Период | Как считается |
| --- | --- | --- |
| «Каждый день» | Каждый день челленджа | Балл за каждую цель, выполненную в этот день |
| «Каждые N дней» | Окно из N дней | Результаты внутри окна складываются, балл за каждую закрытую цель |
| «Всего за период» | Весь челлендж | Балл за каждую цель, накопленная сумма по которой достигла цели |

Как подтвердить результат:

- **Фото** — для шагов, пробежки, сна и других целей с типом «Фото».
- **Видео** — для отжиманий, приседаний, планки, пресса и других целей с типом
  «Видео».
- **Фото или видео** — для целей с типом «Любое».
- **Галочка участника** — подходит для любой цели. Автор отметки не может
  подтвердить сам себя. Подтверждение ставится отдельно по каждой цели и
  действует, пока результат не изменён. Снять галочку можно до окончания
  челленджа; после финиша результаты не меняются.

Цвета дневника: зелёный — все цели периода закрыты, жёлтый — есть частичный
прогресс, красный — период пропущен. После окончания челленджа первые три места
получают медали, которые отображаются в профиле и на сайте.

## Настройка синхронизации

1. Установите APK и зарегистрируйтесь. Код подтверждения появится на экране.
2. Заполните профиль.
3. Откройте **Настройки → Синхронизация** и включите автосинхронизацию, если
   нужно отправлять изменения сразу после сохранения.
4. Нажмите «Синхронизировать» на главном экране или в настройках.

При синхронизации приложение сначала читает удалённые JSON, объединяет их с
локальными данными, затем загружает новые медиафайлы и пересобирает
`standings.json`. Если файл уже существует, приложение автоматически получает
его версию (`sha`) и повторяет загрузку.

Ограничения медиа: видео сжимается до 720p (видео ~1,5 Мбит/с, звук AAC
96 кбит/с), итоговый файл — до 25 МБ, исходный — до 300 МБ. Исходное фото — до
40 МБ (сжимается до 1800 px), аватар — до 8 МБ. Файлы больше 35 МБ не
отправляются в GitHub.

## Обновление приложения

**Настройки → О программе → Обновить** проверяет последний релиз на GitHub.
Если версия новее, приложение предложит скачать APK, проверит пакет и подпись
и запустит системный установщик. Для установки может потребоваться разрешение
«Установка неизвестных приложений». Обновление ставится поверх текущей версии
только с той же подписью.

## Структура проекта

```
app/                  Android-приложение на Kotlin + Jetpack Compose
  src/main/java/      Экраны, модели, подсчёт баллов, GitHub-синхронизация
  src/test/java/      Unit-тесты движка челленджей
assets/               Стили, скрипты и favicon сайта
data/                 JSON, который создаёт и обновляет приложение
index.html            Главная страница GitHub Pages
```

Пустые JSON в `data/` — это корректные placeholder-файлы для первого запуска
сайта. Приложение заменит их при первой синхронизации. Вручную редактировать
эти файлы не нужно.

## Сборка

Нужны JDK 17 и Android SDK с platform/build-tools 35.

```powershell
$env:JAVA_HOME = "путь\к\jdk-17"
$env:ANDROID_HOME = "путь\к\android-sdk"
$env:ANDROID_SDK_ROOT = $env:ANDROID_HOME

.\gradlew.bat :app:testDebugUnitTest --console=plain
.\gradlew.bat :app:lintRelease --console=plain
.\gradlew.bat :app:assembleRelease --console=plain
```

Готовый APK: `app\build\outputs\apk\release\app-release.apk`.

## Ограничения

- Подтверждение email демонстрационное: код показывается в приложении, письма не
  отправляются.
- Нет серверной модерации: корректность результатов проверяют другие участники
  челленджа — галочкой или просмотром фото/видео.
- Приложение и сайт не собирают аналитику и не используют сторонние SDK, кроме
  сетевых запросов к GitHub.
