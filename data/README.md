# data

Служебные JSON-файлы приложения «Онлайн челленджи».

- `catalog.json` — общий каталог активностей;
- `challenges.json` — челленджи и списки участников;
- `profiles.json` — профили, аватары и медали;
- `checkins.json` — отметки и пути к подтверждениям;
- `standings.json` — готовый рейтинг для сайта.

Файлы создаются и обновляются приложением при синхронизации с GitHub. Пустые
массивы в репозитории — стартовое состояние. Вручную редактировать файлы не
нужно: при следующей синхронизации приложение объединит данные и перезапишет
их.
