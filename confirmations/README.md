# confirmations

Публичные файлы фото и видео, которые участники прикладывают к отметкам.

- `<код участника>/<id челленджа>/` — файлы подтверждений.

Файлы загружаются приложением при синхронизации и остаются альтернативой
взаимной проверке: балл засчитывается, если есть подходящее фото/видео или
галочка другого участника. Манифест больше не нужен: сайт показывает только
итоги, места и имена подтвердивших, без ссылок на файлы. Демо-данные сюда не
попадают.
