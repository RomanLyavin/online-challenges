# confirmations

Публичные подтверждения результатов челленджей.

- `manifest.json` — список всех загруженных фото и видео для сайта;
- `<код участника>/<id челленджа>/` — файлы подтверждений.

Каталоги и манифест создаются приложением при синхронизации. Не удаляйте файлы,
если хотите сохранить историю подтверждений: ссылки на них используются на сайте
и в статистике. Демо-данные сюда не попадают.
